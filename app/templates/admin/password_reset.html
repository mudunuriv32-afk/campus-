Administrative Security Standards
15-Minute Expiration

Temporary passwords auto-expire after 15 minutes. Once expired, the user must request a fresh reset from an administrator.

Immediate Invalidation

Issuing a new temporary password immediately supersedes and invalidates any previous passwords or prior temporary credentials.

Forced Password Change

The user is immediately redirected to a mandatory password change screen upon login and cannot access any other features until updated.

Immutable Audit Trail

Every reset generates a permanent record with administrator ID, target user ID, timestamps, and status for accountability.

Notice to Administrators:

Never convey temporary credentials across unencrypted or insecure public channels. Verify the recipient's identity in person or via their verified college institutional contact before handing over temporary access.
